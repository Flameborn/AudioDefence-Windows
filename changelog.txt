unrelease:
The game checks for updates by itself and tells you when one is out. An update downloads only the files that changed, so a small fix is a small download, and your progress, settings and keys are untouched.
The main menu has a Check for updates button, between Settings and Quit, for when you want to ask it yourself.
The main menu's Check for updates button tells you which version you are on. Run from source, it says updating is not available there instead, because a copy from GitHub updates with git.
The pause menu has a Restart challenge button, between Resume and End Game. A challenge you have already lost no longer has to be played to the end. Endless games do not have it.
The screen at the end of a run has a Copy results button, after an endless game and after a challenge you won or lost. It puts the results on the clipboard so you can paste them to somebody.
The screen after a failed challenge reads out your kills, accuracy and time, which it never used to say.
Changing a tarot card reads the new card out. Before, it changed in silence and you had to arrow off it and back to hear what you had.
Melee is on both Control keys now, left and right, so whichever hand is free can reach it.
The statistics screen counts the coins and diamonds you earn. Money earned and Diamonds collected used to stay at nought for ever.
A tarot card says how many diamonds you have now. Spend some in the armory, come straight back, and it used to quote the old number.
After upgrading a power-up, the Upgrade button shows the new price at once. It used to offer the old one for about a second.
Copy results puts a short list on the clipboard now: just the numbers, without the section headings or the game's version. After an Endless game it starts with the two tarot cards you played with.
Copying results says Results copied to clipboard, instead of a long sentence.
The Menus tab in Settings is called Miscellaneous now and comes last. Besides the menu arrows and remember cursor position, it has the switch for checking for updates when the game starts.
The Miscellaneous tab has a Reset all settings button. It sets everything back to default, except your keys.
The Restore aiming defaults and Restore menu defaults buttons are removed. Use Reset all settings instead.
