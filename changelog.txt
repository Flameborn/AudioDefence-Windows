unrelease:
Changing a tarot card reads the new card out now. The card changed under the cursor without saying anything, so the only way to hear what you had drawn was to arrow off it and back on.
The pause menu has a Restart challenge button, between Resume and End Game. A challenge you have already lost, on time or on accuracy, no longer has to be played out to the end or ended and then found again in the list. Endless games do not have it, having no challenge to restart.

26.09.20-4:
The screen at the end of a run has a Copy results button now: after an endless game, after a challenge you completed, and after one you failed. It puts what the screen tells you on the clipboard, so you can paste it into a message and show somebody what you did.
The screen after a failed challenge also reads out your kills, accuracy and time, which it never used to say at all.

26.09.20-3:
The main menu has a Check for updates button, between Settings and Quit. The game still looks by itself when it starts and only speaks up when there is something to install, so the button is there for when you want to ask it yourself.

26.09.20-2:
The game now checks for updates by itself. When a newer version is out, the main menu says so and asks whether to install it; answering no will not ask again for that version. Settings has an Updates page with the version you are on, a Check for updates button, and a switch for whether it checks when the game starts. An update only downloads the files that actually changed, so a small fix is a small download rather than the whole game again, and your progress, settings and keys are untouched.
The melee attack is on both Control keys now, left and right, instead of the left one only. Whichever hand is not on the turn keys can reach it.
The statistics screen never counted the coins and diamonds you earned, so "Money earned" and "Diamonds collected" stayed at nought. They count now.
No more tarot card said how many diamonds you had when it was dealt. Spend some in the armory, come straight back, and the card still quoted the old number until something else rebuilt it. 
After upgrading a power-up, the Upgrade button offered the old price for about a second, so stepping off it and back inside that second read a price you could no longer pay. Now has been fixed!

Initial release.
