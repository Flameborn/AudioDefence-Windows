unrelease:
The game checks for updates by itself and tells you when one is out. An update downloads only the files that changed, so a small fix is a small download, and your progress, settings and keys are untouched.
The main menu has a Check for updates button, between Settings and Quit, for when you want to ask it yourself. It also tells you which version you are on. Run from source, it says updating is not available there instead, because a copy from GitHub updates with git.
The pause menu has a Restart challenge button, between Resume and End Game. A challenge you have already lost no longer has to be played to the end. Endless games do not have it.
The screen at the end of a run has a Copy results button, after an endless game and after a challenge you won or lost. It puts a short list of your results on the clipboard so you can paste them to somebody.
The screen after a failed challenge reads out your kills, accuracy and time, which it never used to say.
Changing a tarot card reads the new card out. Before, it changed in silence and you had to arrow off it and back to hear what you had.
Melee is on both Control keys now by default, left and right, so whichever hand is free can reach it.
In Info, the Statistics screen now counts the coins and diamonds you earn. Money earned and Diamonds collected always said 0 before.
On the tarot card screen, a card now tells you the right number of diamonds you have. After spending diamonds in the armory, it used to still say the old number.
After upgrading a power-up, the Upgrade button shows the new price at once. It used to offer the old one for about a second.
The Menus tab in Settings is called Miscellaneous now and comes last. It has the menu arrows, remember cursor position, tutorial text, which has moved there from the Sound tab, and the switch for checking for updates when the game starts.
The Miscellaneous tab has a Reset all settings button. It sets everything back to default, except your keys.
Two zombies of the same kind no longer cut off each other's sound. One of them could go quiet and keep walking towards you.
After a revive, being killed by the same kind of zombie again plays its attack sound. It used to be silent, every time with the Shield zombie.
Page Up and Page Down set the volume of the menu music, on any menu. It goes from 100%, as loud as the music has always been, down to silent, and does nothing in a game.
The game keeps its version number inside itself now, not in a VERSION file beside it, so editing or deleting that file can no longer stop it from updating. A VERSION file left from an older version is not used any more.
When an update is offered, No now only means not now, and the game asks again the next time it starts. To stop being asked about that version, there is a new Skip this version button. A newer version is still offered, and Check for updates on the main menu still finds a skipped one.
The screens at the end of a run read one result per line, the same as Copy results, and Copy results comes before the other buttons. After Endless, the first line is your tarot cards. After a challenge, it is the challenge name and whether you completed or failed it.
The Play again button after an Endless game is called Close. It still takes you back to the Endless screen.
You can play with a game controller, like a DualSense, DualShock, Xbox or Switch Pro controller. Either stick turns, slowly with a small push and fast when pushed all the way. R2 fires, R1 is melee, L1 switches weapon and L2 reloads, or in Gesture mode, flick a stick up or down. Options pauses.
A controller works in the menus too: the D-pad or a stick moves, Cross selects, Circle goes back, L1 and R1 change tab, and L2 and R2 set the menu music volume.
A controller vibrates with the heartbeat when a zombie is close, harder the closer it is, and when a shot or a melee attack hits.
Shaking the controller swings your melee weapon in Gesture mode, like shaking the phone did.
On a DualSense, R2 feels like a gun's trigger while you play, and in Button mode L2 has a light pull for reloading.
Settings has a Joystick tab. It names the controller you have connected, turns vibration and the trigger feel on or off, and lets you change which button does what.
The Shield zombie, and a few others, no longer die in silence when the killing hit is critical, which happened often with melee. Their hit sound was cut off and no death sound played.
When two zombies die close together at the end of a wave, the second one's death sound is no longer cut off.
A DualSense plugged in by USB plays the heartbeat you hear in its grips, using the fine haptics PlayStation games use instead of plain rumble.
